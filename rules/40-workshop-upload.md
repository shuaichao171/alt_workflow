# 模组工坊上传授权

- **只有用户在本次任务中明确要求上传、发布或更新创意工坊物品，才允许执行上传。** 可以执行“修好后上传”这类明确指令，但必须先满足用户条件；条件未满足时不得提交。
- 开发、修复、测试、打包、修改版本、整理上传方案、查询列表，以及确认名称或 ID，都不等于授权上传。“更新模组”这类未明确涉及工坊的说法不能自行解释成发布。未获明确上传指令时完成用户已要求的工作即可，不自动追加上传步骤。
- 该限制适用于所有工坊写入入口：`upload` 命令、其他脚本、原生 API、上传器界面，以及仅更新标题、简介、封面、Tags 或可见性的操作。不得为了测试工作流而真实发布。
- 上传指令只覆盖本次指定的模组、游戏、目标和操作；不得编造授权、复用旧任务授权、扩大范围或把待确认改成已授权。用户取消、改为只准备或明确暂不上传时立即停止提交。
- 从列表按名称推断的 ID 仍须获得用户明确确认，详见 [上传技能](../skills/steam-workshop-upload/SKILL.md)。**确认 ID 与授权上传是两个独立条件**；同一句真实答复可同时满足两者，但“ID 没错”本身不授权上传。
- `plan` / `check` 是离线准备，`list` / `inspect` 是只读查询；仅按当前任务需要使用。配置中的授权记录只是执行检查，不能代替真实用户指令；没有指令时不得填写为已授权，也不得用 `force` 绕过。
