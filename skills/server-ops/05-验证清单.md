# 05 · 验证清单

> 变更之后按层往下走，**不要只看 `docker compose ps` 是 Up 就宣布完成**。

## L0 进程与健康

```bash
ssh <别名> 'docker ps --format "{{.Names}}|{{.Status}}|{{.Ports}}"'
ssh <别名> 'docker inspect -f "{{.State.Health.Status}}" <容器>'      # 期望 healthy
python scripts/server.py health --port 8787                          # 期望 {"ok":true,...}
```

`/health` 这类端点通常顺带返回关键指标（账号数、积分、模型数），**先看数字对不对**再往下走。

## L1 管理 API（功能面）

```bash
ssh <别名> 'P=$(grep -m1 "^<ADMIN_PW_KEY>=" <VPS_<服务>_DEPLOY_DIR>/.env | cut -d= -f2-)
  curl -s -H "Authorization: Bearer $P" http://127.0.0.1:8787/admin/api/accounts | jq ".summary"'
```

检查：条数/状态、`cooling=0`、`invalid=0`、积分是否已刷新、模型目录是否同步。
密码**不要打进日志或回复**（用变量传，别把值贴出来）。

## L2 端到端真实请求（最能说明问题）

```bash
# 建一把临时下游密钥 → 用真实请求打通 → 立刻删掉
KEY=$(ssh <别名> 'P=$(grep -m1 "^<ADMIN_PW_KEY>=" <VPS_<服务>_DEPLOY_DIR>/.env | cut -d= -f2-)
  curl -s -X POST http://127.0.0.1:8787/admin/api/keys -H "Authorization: Bearer $P" \
    -H "Content-Type: application/json" -d "{\"name\":\"tmp-verify\"}" | jq -r .plaintext')

ssh <别名> 'curl -s -m 30 http://127.0.0.1:8787/v1/chat/completions \
  -H "Authorization: Bearer <临时密钥>" -H "Content-Type: application/json" \
  -d "{\"model\":\"<便宜模型>\",\"messages\":[{\"role\":\"user\",\"content\":\"只回复：pong\"}]}"'
```

- 用**最便宜的模型 + 最短提示**，真实调用会消耗上游额度。
- 测完立即 `DELETE /admin/api/keys/<id>`；密钥明文只出现一次，别写进任何文件。
- 返回里 `status=ok` + 有内容 + `points_consumed` 合理 = 鉴权、转发、计费链路都通。

## L3 依赖方（最容易漏）

```bash
ssh <别名> 'docker logs --since 10m <依赖方容器> 2>&1 | grep -iE "<本服务名>|unschedul|transport|refused" | tail -10'
```

- 重启会让依赖方出现一次 transport error，并且**可能把它临时降级**（10 分钟量级），
  期间表现为"pool=0 / no available accounts"。若状态没自愈，按服务档案里的 `recover-state` 步骤恢复。
- 判断依据是**依赖方日志里的请求是否恢复 status 200**，而不是本服务的健康检查。

## L4 数据面

```bash
ssh <别名> 'python3 -c "
import json,time
rows=[json.loads(x) for x in open(\"<VPS_<服务>_DEPLOY_DIR>/data/usage.jsonl\") if x.strip()]
now=time.time()*1000
rec=[r for r in rows if now-r[\"ts\"]<10*60*1000]
print(\"近10分钟\",len(rec))"'          # 宿主机没 node，用 python3
```

- 新增账号/密钥是否**已被真实调用**（首次调用时间应是变更之后）。
- 余额/配额变化方向是否符合预期。

## L5 收尾

- 服务器日志最近 N 分钟**没有新增 error**。
- 临时文件（本机 `.deploy-tmp/`、服务器 `/tmp/*`）已清理。
- 备份路径与 md5、回滚命令已写进回复。
- 新的实测结论已落进 [07-踩坑与实测结论.md](07-踩坑与实测结论.md) 或对应服务档案。
