# 07 常见坑速查

按症状查。原因和写法细节见对应文件。来源括号里的「源码 / 实测」等标注含义见 [README 证据标注](README.md#证据标注)。

## 纠错索引（想当然的做法 → 实际情况）

动手前先扫一遍：这些都是照搬联机版或凭直觉写、在移植中真实出过错的做法。

| 想当然的做法 | 实际情况 | 见 |
|---|---|---|
| `local c = inst:AddComponent("x")` 拿返回值 | 单机 `AddComponent` 不返回组件 | [02](02-API差异速查.md) 第 1 节 |
| 照抄联机版 `Recipe(...)` 参数 | 各 DLC 构造函数签名不同，按 `Common_Recipes` 等探测 | [03](03-技能树配方与界面.md) 4.1 |
| 原地改 `TECH.NONE` 做解锁 | 共享表，Recipe 按引用保存，改一处全坏 | [03](03-技能树配方与界面.md) 4.3 |
| SW/Hamlet 的速度、饥饿修正值也传倍率 | 是相对 1 的加数，要传 `mult - 1` | [02](02-API差异速查.md) 第 2 节 |
| 加 `nointerrupt` 标签就不会被打断 | 单机受击处理忽略它，改用 `not_hit_stunned` | [02](02-API差异速查.md) 第 5 节 |
| 阵营抗性写进 `Combat:GetAttacked` | DST 的抗性在护甲**之后**结算，应钩 `Inventory:ApplyDamage` | [02](02-API差异速查.md) 第 2 节 |
| 监听 `shaved` 事件处理刮胡子 | 单机 `SHAVE` 直接调 `Beard:Shave`，不推该事件 | 本页「功能不生效」 |
| `instant = true` 的动作也会走 SG 播动画 | 单机直接 `bufferedaction:Do()`，绕过 SG | 本页「加载与崩溃」 |
| `inst.sg:HasState(name)` 判断状态 | 单机 SG 实例没有这个方法，状态表在 `inst.sg.sg.states` | 本页「加载与崩溃」 |
| `AddStategraphActionHandler` 只是追加 | 按动作替换原版处理函数，影响所有角色 | 本页「功能不生效」 |
| `GLOBAL.x ~= nil` 判断全局是否存在 | 严格模式下读取本身就报错，用 `rawget(_G, "x")` | 本页「加载与崩溃」 |
| 只改 `.fev` 文件名就换了事件路径 | 路径 = 工程内部名/组/事件，与文件名无关 | [04](04-音效移植.md) 第 3 节 |
| 磁盘上两份 FEV 一样，两个模组就能共用 | 同名内部工程第二次加载报 FMOD error 92 | [04](04-音效移植.md) 第 3 节 |
| 源码里搜不到字面量就说明 prefab 不存在 | 原版常用拼接注册（`"dug_"..name`） | 本页「功能不生效」 |
| 照抄 `GetString(inst, "ANNOUNCE_X")` | 单机第一个参数是角色名，传实体报错 | [02](02-API差异速查.md) 第 5 节 |
| 按联机版标签找实体（如 `tentacle`） | 单机同名 prefab 常没有该标签 | 本页「功能不生效」 |
| 只带 `.fsb` 不带 `.fev` 也能播角色语音 | FSB 只是波形库，没有 FEV 就没有事件路径，注册了也无声 | [04](04-音效移植.md) 第 3 节 |
| 关掉游戏后手动删测试存档 | Steam 云会同步回来，只在游戏内删除 | [06](06-测试与存档安全.md) 第 3 节 |
| 通用名组件文件“API 一样就能共存” | 只有一份被 `require`；动作收集等附加逻辑写在组件文件里会随另一模组的副本消失，要在模组加载时对实际加载的类挂钩 | 本页「功能不生效」 |
| 把坐骑/宠物 `SetInvincible(true)` 只是挡伤害 | 单机 `Hunger:DoDelta` 对无敌实体也直接返回，饥饿值从此不变 | [02](02-API差异速查.md) 第 5 节 |
| 照抄 DST 帽子卸下时 `Hide("HEAD_HAT")` | 单机原版帽子只切 `HEAD_HAIR`，`HEAD_HAT` 被藏后再戴原版帽子头就没了 | 本页「表现与界面」 |
| FEV 里标了 one-shot 的事件会自己结束 | 有的事件（WX `screech/loop`）在单机运行库里一直播放，必须命名播放并在所有退出路径 `KillSound` | [04](04-音效移植.md) 第 3 节 |
| 在 HUD `OnLoseFocus` 钩子里关闭自建轮盘 Screen | `PushScreen` 时新屏 `default_focus:SetFocus()` 的焦点链会触发旧 HUD 的 `OnLoseFocus`（widget 级，不是前端栈切换），轮盘在自己的入栈过程中被钩子关掉；HUD 失焦时轮屏本就不持有焦点，这种关闭逻辑唯一能触发的就是自毁 | 本页「表现与界面」（麦斯威尔 2026-11-07，实测） |
| 用 `TheSim:FindEntities` 断言刚生成的法术实体存在 | 单机 FindEntities 走物理网格，无物理体的实体（陷阱、施法代理）查不到；改用带物理体的实体名或燃料/理智消耗等副作用断言 | 本页「测试与断言」（麦斯威尔 2026-11-07，实测） |

## 加载与崩溃

| 症状 | 原因 | 处理 |
|---|---|---|
| 进入选人界面就闪退，日志无 Lua 报错，前面有 `... is 95x95 but compressed textures must have power of 2 dimensions` | 存档槽 / 选人肖像是非 2 的幂 DXT5，选人界面一绘制就原生崩溃。自动测试直接 `StartSurvivalMode` 不经过选人界面，测不出来 | 贴进 2 的幂画布并改 UV（[05](05-资源与发布.md) 第 2 节）；测试里加前端探针（推 `CharacterSelectScreen` 选中角色停几秒）（沃特 2026-11-07，实测：旧贴图复现崩溃、新贴图通过） |
| 新档世界加载完、玩家出现前进程直接退出，日志无 Lua 报错 | 在角色 prefab 构造函数里调用了 `LocoMotor:UpdateGroundSpeedMultiplier()`：它查询原生 `GroundCreep`/`Flooding`，而玩家在世界填充阶段构造，此时这些数据尚未就绪 | 构造期只记录状态，置 `locomotor.creep_check_timeout = 0` 让 locomotor 下一帧自己刷新（沃特 2026-10-31，实测：改后同一用例通过） |
| 一加载就 FMOD 崩溃 | 声音包注册了两次 | 只在 modmain `Assets` 注册一次（[04](04-音效移植.md)） |
| 和其他移植模组同时启用就 FMOD 报错 92 / 崩溃 | 两个模组各自注册了**同名内部工程**的 FEV（如 wolfgang、woodie、早期 wilson 都用 `wilson_rework`）；磁盘文件相同不代表能同时加载 | 默认按做法 A 重建为独立工程名并同步改 Lua 路径；确实要共用一个包时，只能由一个模组负责加载，其他模组不注册它（[04](04-音效移植.md) 第 3 节，威尔逊 2026-10-31，实测 error 92） |
| 加载报 FMOD 错误 43 | 改了 FEV 工程名但没同步 `OBCT` 计数 | 同步 id 19 / 20 字节数（[04](04-音效移植.md)） |
| 加载即崩，指向字符串文件 | 字符串表缺引号等语法错误 | Lua 5.1 静态编译检查 |
| 延迟加载的 SG / prefab 报未声明全局 | `modimport` 里普通赋值不可见 | 显式 `GLOBAL.X = ...` |
| `AddComponent` 后取到 nil | 单机不返回组件 | 用 `inst.components.X` |
| 配方在 Base 报错 | `Recipe` 多传了 `game_type` | 按 `Common_Recipes` 等探测签名 |
| RoG 下注册图标报错 | `RegisterInventoryItemAtlas` 在 DLC0001 不存在 | 存在性检查 |
| 准星 API 为 nil | `SetValidateFn` 仅哈姆雷特有 | 存在性检查 |
| 哈姆雷特物理/碰撞报错 | 没有 `COLLISION.WORLD` | `GetWorldCollision()` |
| 骑乘一移动就报错 | 占位鞍缺 `GetBonusSpeedMult` / `GetBonusDamage` | 补方法 |
| 坐骑死亡报错 | `Rideable` 死亡监听按真实鞍实体处理 | 拦截 `SetSaddle` |
| 和其他移植模组一起开就出问题 | `scripts/` 同路径文件互相覆盖 | 文件名加角色前缀；通用组件保持联机版 API（[01](01-流程与模组结构.md)）。本机实测 `scripts/dst_functions.lua` 同时存在于沃尔特、沃托克斯、沃特、机器人和两个工坊模组，`require` 缓存后其余模组的垫片完全不执行（机器人 2026-10-31，源码：逐份比对内容不同） |
| 投掷/弹道 `Launch` 崩溃或除以 0 | 缺 `yOffset` / `horizontalSpeed`；落点距离过近 | 补字段、给最小前向落点 |
| 读 `bit`、`GetInteriorSpawner` 等报未声明全局 | 单机没有 `bit` 库；`GetInteriorSpawner` 只有哈姆雷特有；`x ~= nil` 本身就触发严格模式 | `rawget(_G, "名字")`（薇诺娜 2026-10-29） |
| 地图生成完原生断言 `mMaskTexture` | 在后端世界之间直接切换 DLC | 先回前端卸载资源再切（[06](06-测试与存档安全.md)） |
| 加载/进世界即崩：`stategraph.lua: table index is nil` | `AddStategraphActionHandler(ACTIONS.X, ...)` 在 `ACTIONS.X` 还是 nil 时构造（modimport 顺序：SG 文件在 actions 之前） | 先 modimport 动作定义文件，再 SG 文件；或全部放在同一文件里（薇格弗德 2026-10-29） |
| 动作能触发但角色不播自定义动画 | 单机 `instant=true` 的动作直接 `bufferedaction:Do()`，完全绕过 SG 的 ActionHandler | 动画动作不要用 instant；确需 instant 的由 action fn 里显式 `GoToState`（薇格弗德 2026-10-29） |
| `sg:HasState("x")` 判定永假 / 报调用 nil | 单机状态图**实例**没有 `HasState` 方法，也没有 `states` 字段；状态表在模板 `inst.sg.sg.states` 上 | 用 `sg.sg ~= nil and sg.sg.states[name] ~= nil` 或直接 `GoToState`（它自会打印 INVALID STATE）（薇格弗德 2026-10-29） |
| 攻击/使用武器即崩 `GetMaxUses` / `GetDamage` 调用 nil | 单机 Base/RoG 的 `FiniteUses` 无 `GetMaxUses`（字段为 `maxuses`），`Weapon` 无 `GetDamage`（字段为 `damage`） | 按方法存在性探测，回退读字段（薇格弗德 2026-10-29） |

## 功能不生效

| 症状 | 原因 | 处理 |
|---|---|---|
| prefab 构造函数里 `if inst.prefab ~= "x" then return end` 的分支永远不执行 | 单机 `SpawnPrefab` 在 `prefab.fn` 返回**之后**才 `SetPrefabName`，构造期 `inst.prefab` 为 nil | 构造期不要靠 `inst.prefab` 判断；运行期（事件、任务、钩子）再读（沃特 2026-10-31，源码 `mainfunctions.lua`，实测触手预警因此失效） |
| 触手预警等按标签搜索的功能从不触发 | 单机 `prefabs/tentacle.lua` 只加 `monster`/`hostile`/`wet`/`WORM_DANGER`，没有 DST 的 `tentacle` 标签 | 用单机实际标签（`WORM_DANGER`，虫洞和蜂窝也有）搜索后再按 prefab 名过滤（沃特 2026-10-31，源码） |
| 角色地形加速时有时无、蛛网上也不减速 | 另开轮询写 `groundspeedmultiplier`，与 locomotor 每 0.5 秒的重置互相覆盖 | 包装 `UpdateGroundSpeedMultiplier`（[02](02-API差异速查.md) 第 5 节，沃特 2026-10-31，源码） |
| SW/Hamlet 船上溺亡没有角色语音 | `SGwilson` 的 `death_boat` 写死 `dontstarve_DLC002/characters/vanilla/<角色>_drown_voice`，不读 `talker_path_override` | `RemapSoundEvent` 到本角色死亡语音（[04](04-音效移植.md) 第 4 节）（沃特 2026-11-07，源码） |
| 沃特带着贻贝、蛙腿也掉理智 | 按 `fishmeat` 标签判断，SW/Hamlet 给所有海鲜都打了这个标签 | 按 prefab 名单判断（沃特 2026-11-07，源码） |
| 雇来的鱼人跑回家、白天睡觉 | 单机 `mermbrain` 的 `ShouldGoHome` 排在前面；`sleeper` 白天入睡 | 跟随节点插在 `ShouldGoHome` 之前，有 leader 时 `sleeptestfn` 返回 false（沃特 2026-11-07，源码） |
| 技能树顶部标题显示 MISSING NAME | `STRINGS.CHARACTER_NAMES`（选人界面，小写键）和 `STRINGS.NAMES`（实体名，大写键）是两张表；单机 `SpawnPrefab` 在 `SetPrefabName` 里用 `STRINGS.NAMES[大写 prefab]` 回退 `"MISSING NAME"`（四份 entityscript.lua 均有），只注册前者时实体名就是占位符，读 `owner.name` 的界面直接显示它 | 角色注册处补 `STRINGS.NAMES[string.upper(name)] = STRINGS.CHARACTER_NAMES[name]`（walter 已有先例；wurt 2026-11-07 实测复现与修复，同日同构修复 winona/wormwood/wanda/waxwell 未实机；原版 prefab 七个与 wortox 自带 NAMES 不受影响） |
| 技能树界面音效全无 | 音效表写在 `GLOBAL.X_SOUNDS`，界面读 `TUNING.X_SOUNDS`；回退路径指向没加载的 `wilson_rework` | 统一张表、只引用本模组注册的工程（沃特 2026-10-31，源码） |
| 投掷物远距离总落在半路 | 单机 `ComplexProjectile` 把 `horizontalSpeed` 当**总出射速度**，速度不够时固定 30° 抛出（速度 15、重力 35 时最远约 6.4） | 按射程算速度 `sqrt(g*range)*1.1+1` 并设 `usehigharc = true`（薇诺娜投石机，2026-10-29） |
| 结构受击/被锤后消失不见 | 播放了 bank 里不存在的动画（如 `idle_on`、`hit`） | 用 `verify.py` 对照 zip 动画表 |
| 自定义 SG 状态的 `onupdate` 只被调几次且 `dt=0`，位移/计时全失灵 | 单机 SG 调度器对纯 onupdate 状态的唤醒不可靠（实例休眠等待 timeout） | 需要逐帧效果的改用 SG timeline 的 `TimeEvent` 步进（与唱歌状态同机制，已验证）；玩家位移用 Transform 分帧步进而非 `SetMotorVel`（会被 locomotor 逐帧覆写）（薇格弗德 2026-10-29） |
| 其他角色制作栏能看到本角色配方（灰色图标，或在科技站旁可研究） | 配方在模组加载时全局注册，只钩了 `KnowsRecipe`；`ShouldHintRecipe` / `CanPrototypeRecipe` 只看等级，差 1 级以内就提示 | 等级加 `LOST`，并让本角色的 `KnowsRecipe` 返回 true；或包装两个提示函数；或在出生时注册（[03](03-技能树配方与界面.md) 4.2、4.4，沃尔夫冈、薇洛、薇诺娜、麦斯威尔 2026-11-07，源码） |
| 配方全坏或全解锁 | 原地改了共享的 `TECH.NONE` | `deepcopy` |
| 技能加点不生效 | 只改了配置没走 `onactivate` | 效果只由 updater 施加 |
| 读档丢技能 | 组件没存档或加得太晚 | prefab 早期 `AddComponent`，读档后延迟应用 |
| 忠诚没效果 | 单机怪没有 `*_aligned` 标签 | 映射 `shadow` 等旧标签 |
| 动作距离太近、要贴脸才触发 | 距离写在 `Action` 数据表里 | 用第 5 个位置参数 |
| 物品栏右键法术没反应 | 单机右键只执行 `actions[1]`，且不带 `right` 标志 | 放进普通物品栏动作 / 做切换动作 |
| 被打一下就中断传送、施法 | 单机忽略 `nointerrupt` | 改用 `not_hit_stunned` |
| 随从抢走玩家要捡的东西 | 拾取 AI 缺联机版过滤 | 照搬 `FindPickupableItem_filter`，跳过玩家当前动作目标（[02](02-API差异速查.md) 第 5 节） |
| 协助砍挖时掉落翻倍 | 在 `working` 回调里嵌套 `WorkedBy` | 延后一帧并重新检查 |
| 随从采摘没产出 / 凭空复制 | 无 `inventory` 的 `Pick` 不产物；自己 `SpawnPrefab` 产物会复制 | 从真实植物取，产物进随从容器 |
| 宠物每次上下洞穴就多一只 | `GetSaveFollowers` 把随从带去新世界，角色自己的存档又重建一只 | 包装 `GetSaveFollowers`，把角色自管的宠物临时移出随从表；合并已有副本（[02](02-API差异速查.md) 第 5 节，沃尔特 2026-11-05，源码） |
| 宠物喂食不涨饥饿、不会成长，也不会饿 | 为骑乘设了 `health:SetInvincible(true)`，`Hunger:DoDelta` 对无敌实体直接返回 | 给该实体的 hunger 包 `DoDelta`，固定传 `ignore_invincible = true`（沃尔特 2026-11-05，源码） |
| 武器没弹药按 F 一直空挥，移动打断不了 | 玩家攻击由 `wilsonbrain` 的 `ChaseAndAttack` 驱动，没有 `onattackother`/`onmissother` 就不结束，还持续 `locomotor:Stop()` | 不出手的分支 `combat:SetTarget(nil)`，提示加冷却（[02](02-API差异速查.md) 第 5 节，沃尔特 2026-11-05，源码） |
| 灵魂/掉落不触发 | 在等 `entity_droploot` | 改听 `entity_death` |
| 复活技能永远失败 | 死亡前已掉光物品 | 死亡前暂存 |
| 虫洞仍扣理智 | `wormhole.lua` 不检查 `nowormholesanityloss` | 钩虫洞，只抵消那一次 |
| 强壮形态仍被大理石甲减速 | Base 与 SW/Hamlet 的装备减速通道不同 | 两条通道都处理 |
| 加速异常 / 基础速度被永久改坏 | 乘算/加算混用；直接加减 `walkspeed` | 按 DLC 分支，用可逆修正 |
| 伤害、饥饿倍率翻倍 | SW/Hamlet 修正值是相对 1 的加数 | 传 `mult - 1` |
| 投掷后的武器近战失效 | 落地后仍带 `complexprojectile` | 落地移除该组件 |
| 哈姆雷特室内传送后黑屏 | 室内的移动被当成出到室外 | 只有跨房间才切换房间 |
