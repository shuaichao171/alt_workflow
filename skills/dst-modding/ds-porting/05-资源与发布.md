# 05 资源与发布

## 1. 动画与贴图

- 来源：联机版 `DST_DATA_DIR\anim\*.zip`、`images\`；部分角色 build 在动态资源包里（沃特的 `wurt.zip`、`ghost_wurt.zip` 取自联机版动态资源导出目录）。
- **用实际 zip 里的 bank / build / 动画名核对代码**：沃尔特曾因大沃比行走动画名、小沃比进食动画名在 bank 里不存在而不播放。列表可用沃尔特 `_ai_work/anims.py`（git 历史）或 `KTOOLS_DIR` 的 krane 导出。
- **只拷贝单机没有的资源**：和单机本体同名的文件会覆盖原版资源（麦斯威尔移植把这类拷贝移到 `_ai_work/unused_assets/` 停用）。
- **共用 bank 时改成私有 bank**：温蒂的阿比盖尔动画改入私有 bank `wendy_abigail`，不与单机幽灵的 `ghost` bank 混用。
- 编辑、编译、反查 PNG/TEX/SCML 的工具命令见 `DS_PORT_KIT_DIR\references\texture-animation.md`；新做动作走 [../animation/](../animation/README.md) 流程；工具位置见 `KTOOLS_DIR`、`DST_MOD_TOOLS_DIR`。
- 需要新画图（图标、占位贴图、肖像）时同时使用 [../../image-gen/SKILL.md](../../image-gen/SKILL.md)。

## 2. 角色界面资源（新角色）

| 资源 | 要点 |
|---|---|
| 选人立绘 `bigportraits/<角色>.tex/.xml` | 图集元素用 1024×1024 纹理**左上角 512×717** 区域，与原版一致。元素覆盖整张纹理会让选人界面把立绘画成两倍大并偏移（旺达） |
| 选人头像 | 单机用头肩半身像 |
| 地图图标、存档槽头像、骷髅 | 按原版尺寸做 tex/xml，在 `register_character.lua` 注册 |
| 角色台词与名字 | `STRINGS.CHARACTER_TITLES/NAMES/DESCRIPTIONS/QUOTES`、`CHARACTER_GENDERS` |

## 3. 模组图标与创意工坊素材

- `modicon.tex/.xml`：256×256，DXT5；附源图 `modicon.png`。不要借用选人立绘当图标。
- 创意工坊预览图：1024×1024 JPG，标题文字可用游戏自带字体（沃尔特用 Belisa Plumilla）。
- 中英文简介（Steam BBCode）与 `modinfo.lua` 的中英文 `description` 同步更新为当前完整功能。
- 生成图、合成脚本、简介文本放在 `_ai_work/art/`、`_ai_work/workshop/`。

## 4. 发布前检查

1. 版本号递增（`modinfo.lua` 的 `version`）。
2. 静态检查全部通过（[06](06-测试与存档安全.md) 第 1 节），游戏内自动测试通过，并做过移除测试代码后的干净启动。
3. 发布范围用**显式文件清单**，排除 `_ai_work/`、`tools/`、`artifacts/`、测试模组、备份、日志、`undo-log.txt`、`.py` 脚本等开发文件；不要直接压缩整个目录。清单打包工具：`DS_PORT_KIT_DIR\scripts\port-tools.py package-mod`，说明见 `DS_PORT_KIT_DIR\references\mod-release.md`。
4. README 的「与联机版的差异」「兼容性」「已实测 / 未覆盖」是最新的。
5. 上传创意工坊由用户本人操作；AI 只准备候选包和素材，不代为发布。
