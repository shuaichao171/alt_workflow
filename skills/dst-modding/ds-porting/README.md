# 联机版 → 单机版移植（DST → DS）

整理日期：2026-10-29。把《饥荒联机版》的角色、技能树、物品、界面和音效移植到《饥荒》单机版（Base / RoG / SW / Hamlet）时使用。

经验来源：伍迪、沃尔夫冈、沃托克斯、薇洛、威尔逊、薇格弗德、沃姆伍德、沃特、机器人、薇诺娜、麦斯威尔、温蒂、旺达、沃尔特共 14 个移植模组（位于 `DS_GAME_DIR\mods\<角色名>`），以及早期的移植技能包 `DS_PORT_KIT_DIR`。逐个模组的做法见 [08-案例索引](08-案例索引.md)。文中「角色名 + 日期」（如「温蒂 2026-10-28」）表示该结论来自对应移植模组、在该日期实测或核对。

## 证据标注

结论的可信度不同，写法上分开，引用时不要把低一级的说法当成定论：

| 标注 | 含义 | 能说明什么 | 不能说明什么 |
|---|---|---|---|
| 源码 | 在单机源码（写明涉及的 DLC，未写即四份都核对过）里直接确认 | 指定版本里 API 的实际行为 | 在其他 DLC 或游戏更新后仍然成立 |
| 实测 | 在一个移植模组里实机或自动测试复现 | 该模组、该 DLC 组合下确实发生 | 所有模组都会遇到；根因一定如描述 |
| 多模组 | 两个以上**独立实现**的模组分别复现 | 不是个例 | 共用同一份代码或资源的模组不算独立 |
| 推断 | 从源码片段或现象推出，还没复现 | 值得优先排查的方向 | 可以直接当作修复依据 |

- 写法：在来源括号里加标注，如「（威尔逊 2026-10-31，源码）」「（沃姆伍德 2026-10-31，实测）」。
- 2026-10-31 之前的旧条目大多没有标注，按「实测」（单模组经验）对待，用于关键改动前先按 02 的要求在四份源码里复核。
- 推断升级为源码或实测时改标注并更新日期；被推翻的结论直接改正，并在 [07](07-常见坑速查.md) 的纠错索引里留一行旧说法。

## 一句话方法论

> 剥掉 DST 网络层 → 用单机组件与事件重建状态 → 按 DLC 探测处理 API 分叉 → 对照两边源码逐个核对引擎语义 → 复用官方音效包 → 四 DLC 实机自动测试。

## 源码对照位置

只读参考，不改动：

| 环境 | 位置 |
|---|---|
| 联机版脚本 | `DST_DATA_DIR\scripts`（只有脚本包时先解包到工作目录） |
| 单机本体 | `DS_GAME_DIR\data\scripts` |
| 巨人国 RoG | `DS_GAME_DIR\data\DLC0001\scripts` |
| 海难 SW | `DS_GAME_DIR\data\DLC0002\scripts` |
| 哈姆雷特 Hamlet | `DS_GAME_DIR\data\DLC0003\scripts` |
| 单机日志 | `DS_LOG` |

DLC 开启时同名脚本以对应 `DLC000x\scripts` 为准。**单个组件或函数的行为要在四份源码里都核对一遍**，不要只看本体或只看哈姆雷特。

## 与 mod-skills 的关系

[../mod-skills/](../mod-skills/) 下的技能都以联机版源码为基线，移植时只用来理解联机版一侧的原始设计（组件、SG、Brain 的契约）。单机版一侧的写法以本目录和单机源码为准，不要把联机版的网络、Replica、RPC 写法照搬进单机模组。
