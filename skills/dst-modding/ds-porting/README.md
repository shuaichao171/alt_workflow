# 联机版 → 单机版移植（DST → DS）

整理日期：2026-10-29。把《饥荒联机版》的角色、技能树、物品、界面和音效移植到《饥荒》单机版（Base / RoG / SW / Hamlet）时使用。

经验来源：伍迪、沃尔夫冈、沃托克斯、薇洛、威尔逊、薇格弗德、沃姆伍德、沃特、机器人、薇诺娜、麦斯威尔、温蒂、旺达、沃尔特共 14 个移植模组（位于 `DS_GAME_DIR\mods\<角色名>`），以及早期的移植技能包 `DS_PORT_KIT_DIR`。逐个模组的做法见 [08-案例索引](08-案例索引.md)。

## 一句话方法论

> 剥掉 DST 网络层 → 用单机组件与事件重建状态 → 按 DLC 探测处理 API 分叉 → 对照两边源码逐个核对引擎语义 → 复用官方音效包 → 四 DLC 实机自动测试。

## 源码对照位置

只读参考，不改动：

| 环境 | 位置 |
|---|---|
| 联机版脚本 | `DST_DATA_DIR\scripts`（只有脚本包时先解包到工作目录） |
| 单机本体 | `DS_GAME_DIR\data\scripts` |
| 巨人国 RoG | `DS_GAME_DIR\data\DLC0001\scripts` |
| 海难 SW | `DS_GAME_DIR\data\DLC0002\scripts` |
| 哈姆雷特 Hamlet | `DS_GAME_DIR\data\DLC0003\scripts` |
| 单机日志 | `DS_LOG` |

DLC 开启时同名脚本以对应 `DLC000x\scripts` 为准。**单个组件或函数的行为要在四份源码里都核对一遍**，不要只看本体或只看哈姆雷特。

## 与 mod-skills 的关系

[../mod-skills/](../mod-skills/) 下的技能都以联机版源码为基线，移植时只用来理解联机版一侧的原始设计（组件、SG、Brain 的契约）。单机版一侧的写法以本目录和单机源码为准，不要把联机版的网络、Replica、RPC 写法照搬进单机模组。

## 产物落位

移植工作脚本、解析工具、测试模组、备份放在目标模组的 `_ai_work/` 里（发布时排除），不要写进工作流目录。
